# Contributing

Thank you for your interest. CerberusSSH is not accepting outside contributions at the moment.

The interface in this repository builds against a package (the vault, the SSH engine and the terminal) that is kept in a separate, private repository, so a change here cannot be built or tested from this repository alone. For that reason pull requests are not reviewed or merged for now.

To report a security problem, see [`SECURITY.md`](SECURITY.md).
